DEAL v1.2 reference:

Declarations
  export function name(a: int, b: int): int { return a + b; }
  export class Item { sku: string = ""; qty: int = 0; note?: string; }
  Required class fields must have a default. Optional fields use `?:` and take
  no default. Use has(value.note) to test whether an optional field is present.
  Put `// @jsonable` on its own line before `export class` when asked for a
  JSON-serialisable class.
  A class value is built with an object literal: let item: Item = { sku: "A", qty: 1 };
  There is no `new` and no constructor.

Statements
  let total: int = 0;          every statement ends with a semicolon
  total = total + 1;           no ++, no +=, no ternary, no switch
  if (a === b) { } else { }
  while (a < b) { }
  let i: int = 0; while (i < n) { i = i + 1; }
  for (let value: int of values) { }
  break; continue;
  delete config.key; delete config["key"];
  throw { code: "E_NAME", message: "what happened" };
  try { } catch (e) { }        e has type Error, with e.code and e.message

Types
  null boolean int number string bytes table Error
  T[] for arrays, T | null for nullable, ClassName for declared classes
  (a: int) => int for function values
  alias.ClassName for a class imported from another module
  int is signed 32-bit and distinct from number. There are no implicit
  conversions and no truthiness. int(x) and number(x) convert between the two;
  there is no conversion to string.

Expressions
  ! - ** * / % + - < <= > >= === !== && ||
  values[0]                    zero-based indexing
  values.length                a property, not a call
  let empty: int[] = [];       array literal
  values[values.length] = x;   append
  let point: Point = { x: 1, y: 2 };      object literals are context-typed
  let counts: table = { seen: 0 };        table literal
  counts["seen"] = 1; counts.seen = 2;    table entries by key or by field
  let add: (a: int, b: int) => int = function(a: int, b: int): int { return a + b; };
  `${name} is ready`           interpolation accepts string values only
  let buffer: bytes = bytes(8);
  Strings, arrays and tables have no methods. Work on strings through the
  std/string functions below, and on arrays through loops and indexing.

Async
  async function load(id: int): int { return id; }
  let value: int = await load(1);        await applies to a call
